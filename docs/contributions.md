# 我的贡献台账

> 用途：申请材料 / 面试时，能拿出「这些是我做的」的硬证据。
> 用法：每完成一件小事，就在表里加一行。不用写长，一行就够。
> 证据优先放：截图（`docs/evidence/`）、提交号（`git log`）、文件路径。
