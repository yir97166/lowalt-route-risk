## 6. `scripts/build_report_docx.py` 改动点（代码级）

### 6.1 列表续行（P0，影响 7 处）
现状：只有 `line.lstrip().startswith("- ")` 才建 `List Bullet` 段，续行落到普通段落分支。
改法：循环内维护 `pending_list: Paragraph | None`：
- 遇 `- ` 行 → 新建 List Bullet 段，`pending_list = p`；
- 遇非空、且不以 `- ` / `#` / `|` / `>` / `\`\`\`` 开头的行，且 `pending_list is not None` → `pending_list.add_run(line.strip())`（中文续行直接拼接，不加空格）；
- 遇空行 / 标题 / 表格 / 图片 / 列表结束 → `pending_list = None`。
影响 current.docx 段号：5/7/26/56/60/73/75。

### 6.2 参考文献块解析（P0）
现状：按行处理，`^\[\d+\]` 起头行单独成段，续行变普通段落 → p8 的 [6] 中间出现空行、缩进错位。
