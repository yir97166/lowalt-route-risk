# 独立目标基线（不依赖 p95 归一化）

目的：检验「等长重选 + 真绕行」的结论是否依赖累计暴露 C 的 p95 归一化。
脚本：`scripts/make_independent_baseline.py`；结果：`results/independent_baseline.csv`。

## 四个目标

| 目标 | 定义 | 长度 km | P（人·米） | C（代理·米） | 绕行率 |
|---|---|---|---|---|---|
| A 最小长度 | 纯距离 | 7.014 | 8,431,048 | 3,922 | 1.000 |
| B 最小人口暴露 P | Σ 边长 × 两端人口均值 | 14.182 | 2,621,113 | 1,237 | 2.022 |
| C 避让最高 5% 人口格 | 硬阈值约束，不加权 | 7.511 | 5,791,617 | 2,763 | 1.071 |
| D C 加权 λ=1（参考） | 现有方法 | 7.511 | 5,524,547 | 2,626 | 1.071 |

## 结论

1. **不依赖归一化也能得到同一量级的结论**：λ=1 的 C 加权路线在绝对人口暴露 P 上同样下降 **34.5%**（8.43M → 5.52M 人·米），长度 +7.09%。
2. **硬阈值避让**（不走人口最高 5% 的格子）也恰好是 7.511 km、+7.09%，P 下降 31.3%、C 下降 29.6%；说明「多走 7% 换三成暴露」不是 p95 归一化的产物。
3. **纯 P 最小化**会把路线拉到 14.18 km（+102%），P 降到 2.62M；这是极端下界，不作为推荐路线。
4. C 加权路线在同长度下比硬阈值路线略好（P 5.52M vs 5.79M，C 2,626 vs 2,763），因为它允许「穿过少量高密度格但整体更短」。

## 边界

- P 是「人·米」，不含失效概率、坠落轨迹与遮蔽；不能与伤亡人数互换。
- 目标 C 使用 p95 阈值作硬约束，仍是阈值法；但它是约束而非归一化，可作为独立对照。
- 四个目标共用同一图、同一端点吸附规则；B 的端点吸附偏移未单独复核。
