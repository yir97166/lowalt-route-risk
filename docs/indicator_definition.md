# 指标定义与单位（v1.0，2026-11-22）

> 目的：把「累计暴露 2,840.3 m」这类**单位错误**的表述一次性定死，
> 后续所有脚本、图、报告、答辩幻灯统一按本文名词与单位书写。
> 本文只定义本项目自己的指标，不改写 SORA、不声明合规。

## 1. 记号与定义

| 符号 | 名称 | 定义 | 单位 | 取值 |
|---|---|---|---|---|
| `pop_ij` | 格人口 | 人口栅格按格面积聚合后的每格人口数 | 人 | ≥ 0 |
| `p95` | 归一化基准 | AOI 内非零格人口的第 95 百分位 | 人 | > 0 |
| `s` | 遮蔽系数 | 建筑/地形遮挡折减，取 0.30（工程假设，SORA 中「遮蔽」是缓解措施 M1，不是固定乘数） | — | [0, 1) |
| `a(h)` | 高度因子 | 60 m 取 1.00，90/120 m 仅作情景 | — | > 0 |
| `e_ij` | 暴露代理面 | `clip(pop_ij/p95, 0, 1) × severity × (1 − s) × a(h)` | 无量纲 | [0, 1] |
| `l_e` | 边长 | 边的平面长度（200 m 网格：200 或 282.8 m） | m | > 0 |
| `ē_e` | 边暴露强度 | `(e_a + e_b) / 2` | 无量纲 | [0, 1] |
| `L(R)` | 路线长度 | `Σ l_e` | m | > 0 |
| `C(R)` | **等效暴露长度** | `Σ l_e · ē_e` | **代理·米（proxy·m）** | [0, L] |
| `E(R)` | 平均暴露强度 | `C / L` | 无量纲 | [0, 1] |
| `ρ̄(R)` | 沿路人口密度 | `Σ l_e · ρ_e / L`，`ρ_e = pop_e / A_cell` | 人/km² | ≥ 0 |

示例（核心 OD，200 m 网格，λ=0）：

```
L = 14,665.2 m
C = 2,840.3 代理·米     ← 不是「2,840.3 m」
E = C / L = 0.1937      ← 平均暴露强度 19.4%
ρ̄ = 12,838 人/km²
```

## 2. C 为什么不是「米」

`C = Σ l_e · ē_e`，量纲上确实是长度，但它等于「**假设全程以暴露强度 1.0 飞行，等效飞了多少米**」。

- 因为 `ē_e ≤ 1`，恒有 `C ≤ L`，`C` 永远不可能超过路线长度；
- 它同时包含「飞了多远」和「飞得多危险」两个信息，所以**不能**与 `L` 直接比大小，
  也不能说「暴露 2,840 米」——那会让人以为是航路长度；
- 正确说法：「等效暴露长度 C = 2,840 代理·米，相当于全程 19.4% 的路段处于满暴露」。

## 3. 跨分辨率 / 跨实验能不能比

| 量 | 同分辨率、同人口、同遮蔽内 | 跨网格分辨率（100/200/400 m） | 跨人口数据版本 |
|---|---|---|---|
| `L` | 可比 | 有小幅变化（14.548 → 14.817 km，+1.8%） | 可比 |
| `C` | 可比（相对比较） | **不直接可比**：随 `l_e` 与 `ē_e` 的离散化一起变（2.73 / 2.84 / 2.69） | **不可比**（`p95` 变了） |
| `E` | 可比 | 可比（无量纲，抗离散化） | 相对可比（仍受 `p95` 影响） |
| `ρ̄` | 可比 | 可比（人/km²） | 相对可比 |

结论：**跨分辨率/跨数据版本一律报 `E` 与 `ρ̄`；`C` 只在同一套网格内做路线间比较。**

## 4. λ 的量纲与含义

边权 `w_e = l_e × (1 + λ × ē_e)`：

- `l_e` 单位 m，`ē_e` 无量纲 → λ **无量纲**；
- 含义：λ 表示「1 单位暴露强度等价于把这段距离放大 λ 倍」的价格，
  即 λ=1 时「满暴露的 1 米」= 「2 米空地」；
- 因此不同 λ 下的路线差异是**偏好变化**，不是能耗、时间或法规排序；
- λ 的切换阈值本身受遮蔽系数影响（`s`=0.2/0.3/0.4 → 1.125/1.275/1.500），
  报告时应同时给出阈值与遮蔽取值，不能只写「阈值 1.3」。

## 5. 可说 / 不可说（写报告、答辩、作品集统一口径）

| 可以说 | 不能说 |
|---|---|
| 等效暴露长度 C、平均暴露强度 E、沿路人口密度 ρ̄ | 「累计风险 2,840 米」「暴露 2.84 公里」 |
| 在同一套合成人口数据内，路线 A 的 C 比 B 低 17.0% | 「风险降低 17.0%」「伤亡概率下降 17%」 |
| 净空保护区属于「严禁」无人机施放区域，本项目把它设为不可穿越 | 「本项目通过民航审定/合规」 |
| 遮蔽系数 0.30 是工程假设，敏感性 0.2–0.4 结论方向不变 | 「0.30 有文献依据」 |
| λ=1 只产生等长 tie-break（距离 0% 变化） | 「λ=1 牺牲距离换安全」 |
| 结论只在合成人口、示意禁飞区、单层 60 m 内成立 | 任何指向深圳真实人口、真实空域的绝对数字 |

## 6. 与 SORA 的关系（为何不映射）

SORA 的 iGRC 是**离散分级 + 致死概率/撞地能量模型**，输入是飞机参数、人口密度、遮蔽类别与
缓冲距离，输出是「地面/空中风险等级 + 缓解措施」。本项目只有：

- 相对化的人口暴露面（`p95` 归一化 + 遮蔽乘子）；
- 平面格网最短路的加性指标（长度可加、暴露可加）。

二者**没有可换算的数学通道**（把连续 `C` 映射成 iGRC 需要失效概率、坠落角、冲击能量、
暴露人口的实际分布）。本项目因此只把 SORA 当参照系与术语来源，
在报告、README、答辩中一律写明「非审定、非合规、非风险等级」。
