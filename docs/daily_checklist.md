# 每日清单（你自己要做的部分）

> 每天 30–45 分钟，就三件事：**看 → 查 → 留证据**。
> 日期按 PLAN v1.2：Day 1 = 11/17，11/18 为评审/缓冲日不计入，Day 2 = 11/19 … Day 21 = 12/08。
> 哪天断了也别跳：按「第几天」往后推，不要按日期。

## 每天固定动作

1. **看**：我做完的东西，你打开看一眼，觉得不对就直接说。
2. **查**：按当天任务查一个资料 / 定一个数，结论写进 `docs/decisions.md`。
3. **留证据**：截图存 `docs/evidence/`（命名 `20261119-说明.png`），并在 `docs/contributions.md` 记一行。
