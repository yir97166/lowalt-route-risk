# 项目一页说明（对外自我介绍用）

> 用途：向老师、专家、面试官介绍项目时直接照着说；也用来对齐「我们到底做什么、不做什么」。
> 最后更新：2026-11-20

## 1. 一句话

我在做一个**低空航路规划的方法原型**：在深圳中西部 25×19 km、200 m 网格上，
给「最短路线」和「尽量少经过人群上空」两种走法算账，看为了少暴露要多走多少路。

## 2. 30 秒版

无人机送快递、送样本，航线不能只挑最短的——下面是人，掉下来会砸到人。
我把深圳中西部切成 200 m 的格子，用人口数据给每个格子算一个「地面暴露分」，
再在绕开禁飞区的前提下，比较两条路线：

- 最短路：只算距离；
- 低暴露路：经过人多的地方，1 米按更长的距离记账。

结果是两条路线的「距离 vs 暴露」对比，以及不同权重下的权衡曲线。
这是方法演示和硕士申请作品，不是适航审定，也不是能上线的调度系统。

## 3. 两分钟版（按这个顺序讲）

1. **问题**：低空物流的航线，最短不等于最合适；地面人口密度不同，坠落后的后果不同。
2. **做法**：200 m 网格 + 人口栅格 → 每格暴露代理；硬禁飞区直接删节点/删边；
   边权 = 长度 × (1 + λ × 暴露)；Dijkstra 求路线。
3. **对比**：λ=0（最短）vs λ=1（低暴露）vs λ 扫描（0–2）→ 距离—暴露 Pareto 曲线。
4. **验证**：路线不穿硬禁飞区（独立几何库复核）；网格/路线数字都能用 CSV 复算。
5. **结论**：核心案例（罗湖—福田）上，λ=1 不增加距离、把等效暴露 C 降 1.4%（等长 tie-break）；
   λ≈1.1 起才真绕行，多飞 18.9% 换 C −28.1%。报告如实写，不硬凑。
6. **边界**：合成人口数据、示意多边形 + 官方尺寸净空走廊（按「严禁」作硬禁飞，真实审批仍需另说）、
   单层 60 m；不含通信干扰、天气、空对空、失效概率。
   所以它回答「哪条路线上方的人更少」，不回答「这条路是否合规/是否安全」。

## 4. 最容易误解的三件事（先自己说清）

| 别人可能以为 | 实际是 |
|---|---|
| 你们在判断这条航线**是否符合规则** | 不是。我们只做几何硬约束（示意禁飞区 + 官方尺寸净空走廊），**不下合规结论**，也不判断能否获批 |
| 你们在算**坠机概率/伤亡人数** | 不算。只算「坠落点下方人口」的相对代理，失效概率未知，不能换算成伤亡 |
| 这是一个能用的**飞行调度系统** | 不是。是离线的方法原型 + 作品集，不做实时、天气、多机协同、UI |

## 5. 最终会产出什么（12/08 前）

| 产出 | 形式 | 用途 |
|---|---|---|
| GitHub 仓库 | 公开 repo + README + 一键复现 | 证明代码与可复现性 |
| 中文技术报告 | 6–8 页 PDF | 申请作品集主件 |
| 英文摘要 | 1 页 | 申请材料附件 |
| 3 张核心图 | PNG ≥300 dpi | 人口暴露热力图、路线对比图、Pareto 曲线 |
| 结果表 | `results/*.csv` | 所有数字可复算 |
| 测试 | `pytest` 全绿 | 证明不是"跑通一次" |
| 3 分钟英文视频 | `report/demo.mp4` | 展示讲解 |
| 过程记录 | `docs/decisions.md`、`assumptions.md`、`contributions.md` | 证明参数有出处、工作可追溯 |

**不会产出**：适航/安全符合性声明、真实飞行航路、审批材料、上线系统。

## 6. 可以拿去问专业人士的 5 个问题

1. 深圳 120 m 以下（真高）的无人机物流飞行，实际审批流程和主管单位是什么？
2. 机场净空保护区对物流无人机是"原则禁止"还是"可批"，5 km/10 km 这类缓冲在实际执法中怎么把握？
3. 学术上衡量"地面人口暴露"有没有比 `Σ(人口密度×航段长度)` 更标准的指标？
4. 地面遮蔽系数 0.30、高度因子 0.85/0.70 这类参数，有没有可引用的文献或 SORA 条款？
5. 通信/电磁干扰能否用公开的基站或频谱数据做近似？值不值得为它单开一层风险？

## 7. 一句话收尾（面试/答辩用）

> 这个项目不证明"无人机安全"，它证明的是：**在同样的规则约束下，把地面人口暴露
> 纳入航线代价，可以用可复现的方式量化"少暴露要付多少距离代价"**——以及哪些结论
> 在现有数据下根本不能下。
