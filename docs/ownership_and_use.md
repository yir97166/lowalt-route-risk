# 成果归属、证据链与用途（给自己看的说明）

> 最后更新：2026-11-23
> 这份文档回答两个问题：**怎么证明这个项目是我做的？我能拿它去干什么？**

## 1. 先说结论

- **能证明的**：选题、边界、原始资料、关键决策、结果核对是**你**做的；代码/实验/初稿是
  **AI 辅助**完成、经你核对。这个组合在硕士申请、面试、课程项目里是**正常且可接受**的。
- **不能证明的**：不能证明「所有代码都是你一行行敲的」——也不该这样声称。
- **不算证据的**：git 提交作者名（可以随便设）、README 里写名字、口头说「我做的」。

评审/面试真正认的是：**你能把这个项目讲清楚、能解释每个数字怎么来的、能现场改动并说出后果。**

## 2. 证据链（从强到弱）

| 强度 | 证据 | 在哪 |
|---|---|---|
| 强 | 你能现场解释每个关键数字（4,982 格、7.014 km、λ≈1.1），并说出为什么 | 面试/答辩现场 |
| 强 | 你自己动手跑过、改过：`run_all.py` 截图、改一个参数看结果变化、手算核对一行 CSV | 你的截图/录屏 |
| 强 | 原始资料是你找的、你核对的：通告、AIP 航图、净空尺寸 | `01_原始资料/`、`docs/data_sources.md` |
| 中强 | 决策是你拍的：净空区改硬禁飞、换核心 OD、λ 口径、数据降级 | `docs/decisions.md`（20+ 条） |
| 中 | 贡献台账逐行记录「你提出的问题/你做的决策/你怎么验证」 | `docs/contributions.md` |
| 中 | 提交历史显示迭代过程与日期 | `git log` |
| 弱 | AI 辅助说明（诚实披露，但不等于你做了什么） | README、`docs/contributions.md` |

## 3. 三条「加强归属」的最小动作（每次 5–10 分钟）

1. **亲手跑一次并截图**：在你的终端跑 `.\venv\Scripts\python.exe scripts\run_all.py`，
   截「12 steps finished」那屏，存 `docs/evidence/2026xxxx-runall.png`。
2. **亲手改一个参数**：比如把 `configs/aoi.yaml` 里 `shelter` 从 0.30 改 0.20，重跑
   `make_pareto.py`，看阈值从 1.100 变到 0.975，截图存证，并在 contributions 记一行。
3. **手算核对一个数**：拿 `results/scenario_buffer.csv`，用计算器算 4,982/12,544 = 39.7%，
   截图；或手算核心 OD 的绕行率 7.014/6.675≈1.051。

> 这三件事做完，你在面试里就能说「这个数我自己复算过」，而不是「AI 说的」。

## 4. 能拿去干什么

**可以：**

- 硕士申请作品集（低空经济 / UTM / 交通 / 城市规划 / 地理信息方向）：
  证明你会写可复现代码、懂数据边界、能把一个工程问题做完。
- 简历项目经历 + 个人陈述（PS）里的一段具体故事。
- 面试/答辩：一个完整的「问题→方法→验证→局限」案例。
- 课程大作业 / 毕业论文的**前期原型**（需扩展真实数据与方法对比）。
- GitHub 公开项目，展示工程习惯（测试、复现、决策记录）。

**不可以（现在这个版本）：**

- 适航审定、安全符合性、合规判断——项目里反复写了「不构成」。
- 真实航线规划或飞行依据——人口是合成的、禁飞区是示意的。
- 学术论文投稿：样本（1 个城市、合成数据）、方法创新、文献综述都还不够；
  最多做 demo/workshop，或作为申请材料。
- 商业运行系统——没有实时、天气、多机、通信。

## 6. 面试时最可能被问的 3 个问题（提前准备）

1. 「为什么核心 OD 是罗湖—福田，不是深圳北—深圳湾？」
   → 净空区按通告「严禁」作硬禁飞后，深圳北—深圳湾终点落在走廊内；不挪端点，换一个
   全程在走廊外、任务背景成立（跨境快件）的 OD。
2. 「λ=1 为什么长度不变，是不是没效果？」
   → 8 邻接网格有大量等长路径，λ=1 只在等长解里挑低暴露（tie-break，C −1.4%）；
   真绕行阈值在 λ≈1.1，λ≥1.1 才 +18.9% 距离换 C −28.1%。
3. 「高度 120 m 是不是更安全？」
   → 不是。模型里没有垂直代价，高度只把暴露整体乘 0.70，等价于把 λ 换成 0.7λ；
   路线集合不变、阈值右移到 1.575。不能据此下安全结论。

## 7. 日常汇报偏好（给自己/AI 的备注）

每天做完，用**大白话**说清三件事，再给数字：

1. 今天干了什么（一句话，像跟朋友解释）；
2. 为什么要这么做、结果说明什么；
3. 你要看什么 / 要做什么（最多 2–3 件，10 分钟内）。

术语和表格可以有，但必须先用大白话讲一遍。
